FUNDAMENTALS OF COMPUTING BINARY CALCULATOR WEBSITE

INTRODUCTION

This project was developed as part of the Fundamentals of Computing course. The main purpose of the project is to demonstrate our understanding of computing concepts through the development of an interactive website featuring a Binary Calculator.

The website provides information about topics covered throughout the course while allowing users to perform mathematical calculations using binary and decimal number systems.

The website also features a Digital Forest theme, combining elements of nature and technology through a dark green color scheme, glowing effects, and a modern interface.

PROJECT OBJECTIVES

The main objectives of this project are:

To demonstrate an understanding of binary number systems.
To develop a functional Binary Calculator.
To apply programming and web development skills.
To understand how HTML, CSS, and JavaScript work together.
To demonstrate knowledge gained throughout the Fundamentals of Computing course.
To encourage teamwork, collaboration, and problem-solving.
WEBSITE FEATURES

The website consists of five main sections:

HOME: Provides an introduction to the project and the Fundamentals of Computing course.

BINARY CALCULATOR: Allows users to perform addition, subtraction, multiplication, and division using unsigned binary, signed binary (Two's Complement), and decimal number systems. The Decimal number system was an addition added purely out of self interest and validation of functionality.

MEMBERS: Provides a short Biography, and photo of the group members.

VIDEO GALLERY: Contains the videos of each members' Video Assignment.

DOCUMENTATION: Provides supporting information and documentation related to the project.

DESIGN AND THEME

The website follows a Digital Forest theme, inspired by the combination of nature and technology.

The design uses dark forest-like, green backgrounds, emerald highlights, glowing elements, and modern interface styling to create a futuristic appearance.

The purpose of this theme is to make the website visually appealing while maintaining readability and ease of navigation.

PROJECT STRUCTURE

The project contains the following files:

index.html – Main structure and content of the website.
style.css – Website styling and visual design.
script.js – Website navigation and calculator functionality.
images/ – Folder containing images used throughout the website.
README.md – Project description and documentation.
HOW TO ACCESS THE WEBSITE

The website is hosted using GitHub Pages.

Users can access the website through the published GitHub Pages link.

To run the project locally:

Download or clone the project repository.
Open the downloaded project folder.
Locate the index.html file.
Open the file using a web browser.
Navigate through the different website sections.
